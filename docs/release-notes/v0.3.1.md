UGClient (UFACTORY Genesis Client) is a desktop client for kinematics, dynamics, 3D visualization, and optional physical arm control of UFACTORY robot arms, built on [ufactory_genesis](https://github.com/xArm-Developer/ufactory_genesis) and Pinocchio.

## Real robot control (xArm 6)
UGClient now supports connecting to a physical UFACTORY controller via `xarm-python-sdk` (verified on xArm 6, default IP `192.168.1.60`) while always starting in **simulation mode** by default:
- **Connection & status:** Click the header connection pill to connect/disconnect, inspect detected model, firmware, motor enable state, controller state/mode, and error/warning codes, and stream live joint/TCP telemetry to the 3D stage at 15 Hz.
- **Live motor enable detection:** On connect, UGClient reads the controller's hardware `motor_enable_states` and `motor_brake_states`. If the arm is already enabled with no fault, jogging unlocks immediately without prompting to re-enable.
- **Jogging & safety guards:**
  - Verifies controller `(axis, device_type)` against supported models and locks the 3D robot model selector while connected.
  - Resets speed to `20%` upon entering real-robot mode (`1%–100%` linear speed maps to `2.3–230 mm/s`, orientation `1–40 °/s`, joints `1–45 °/s`).
  - Continuous velocity jogging (`Mode 4` / `Mode 5`) issues a continuous velocity command (`duration=0`) once per hold/speed change, backed by a `100 ms` heartbeat, a `0.4 s` sidecar watchdog, and per-model safety boundary lookahead.
  - Releasing a jog / Home / Align button performs a smooth deceleration stop (`set_state(6)`, with automatic fallback to `set_state(4)` on older firmware), while the red **STOP** button, boundary violations, and watchdog timeouts trigger an immediate lock-free stop (`set_state(4)`).
  - Controller errors are never cleared automatically (manual Clear Error with confirmation only). Writing `TCP Offset` or `TCP Payload` back to the controller requires the arm to be stationary and explicit confirmation.

## Two-column workbench & 3D stage refinements
- Redesigned light two-column workbench layout with a full-height 3D stage on the left and a collapsible tabbed control sidebar (`Cartesian control` / `Joint control`, `End effector`, `TCP Offset`, `TCP Payload`) on the right.
- Added a **collapse/expand button** to the top-right 3D stage telemetry card (TCP pose & joint angles); when collapsed it shrinks to a compact header pill, and when expanded 3D orbit drag still passes through the readout area.
- Simplified the top header, connection dialog, and 3D stage toolbar (removed the unused 3D `COM` toggle/overlay while keeping `TCP Payload` configuration intact).

## Synced upstream `ufactory_genesis` v0.3.9 (`b33810e`)
- Migrated robot/end-effector asset composition and metadata loading to upstream `assembly.yaml`.
- Added **Vacuum Gripper** (`vacuum_gripper`) support on UF850 and xArm 5/6/7, plus `STLLoader` support in the 3D viewport for STL end-effector meshes (e.g., Lite 6 gripper fingers).
- Default TCP offsets for all end effectors are now parsed directly in memory from upstream composed URDFs (`Gripper G2` `173.5 mm`, `BIO Gripper G2` `[157.639, -0.035, 57.516, 0, 0, -0.36]`, `Vacuum Gripper` `126.0 mm`, `Lite6 Gripper` `83.6 mm`, `Lite6 Vacuum Gripper` `61.0 mm`).

## Install / upgrade

### Linux (Ubuntu 22.04+, x86_64)
```bash
sha256sum -c SHA256SUMS.txt --ignore-missing
sudo apt install ./ugclient_0.3.1_amd64.deb
ugclient
```

### Windows 10+ (x86_64)
Download `ugclient_0.3.1_x64-setup.exe` and run the installer (English / Simplified Chinese). Verify the checksum against `SHA256SUMS.txt`. Because development builds are unsigned, Windows SmartScreen may show an "Unknown publisher" prompt on first launch.

## Supported models
UF850, xArm 5 / xArm 6 / xArm 7 (`_1305` revision only), Lite 6.

## Known issues
- Physical robot control has been hardware-verified on **xArm 6**; other supported models share the same adapter and are pending physical HIL verification.
- The joint torque table and target-pose IK form still have no UI (the sidecar API `dyn.gravity`, `check.pose`, `kin.ik` remains available).
- Installers are large (~100 MB) due to the bundled Pinocchio sidecar and are currently **unsigned**; macOS is not supported.
